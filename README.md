# homebrew-tap

General-purpose [Homebrew](https://brew.sh) tap for CLI tools maintained by
[matbur](https://github.com/matbur). A tap is just a Git repository of
`Formula/*.rb` files, so this one hosts formulas of any number of apps side
by side — each app keeps its own release pipeline and pushes only its own
formula.

## Usage

```bash
brew install matbur/tap/git-prev-branch
```

`brew` taps this repository automatically as part of the command above (an
explicit `brew tap matbur/tap` works too), and `brew upgrade` keeps the
installed formulae current.

## Formulae

| Formula | Source repository |
| ------- | ----------------- |
| `git-prev-branch` | [matbur/git-prev-branch](https://github.com/matbur/git-prev-branch) |

## How a formula gets updated

Every formula is regenerated by the CI of its source repository when a new
`vX.Y.Z` release is published: it points at the prebuilt release tarballs
(macOS and Linux, amd64 and arm64) and pins their sha256 checksums from the
release's `SHA256SUMS`. The generated file always lives in `Formula/` and is
committed by the release pipeline, never by hand.
